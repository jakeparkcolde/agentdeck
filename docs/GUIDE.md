## 2. 설치

### 2-1. 기본 도구 확인

터미널을 열고(Spotlight에서 "터미널" 검색) 아래를 입력해 보세요.

```bash
python3 --version   # Python 3.11 이상이면 OK
git --version
```

없다고 나오면 [Homebrew](https://brew.sh)를 설치한 뒤 다음을 실행하세요.

```bash
brew install python git
```

### 2-2. 내려받고 설치하기

```bash
git clone https://github.com/jakeparkcolde/agentdeck.git
cd agentdeck
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp config.example.json config.json
```

### 2-3. 처음 실행

1. **Ulanzi Studio를 완전히 종료하세요.** 메뉴 막대 아이콘에서 종료까지 해 주세요. 두 프로그램이 장치를 동시에 쓰면 충돌합니다.
2. 장치를 USB로 연결하세요.
3. 실행합니다.
   ```bash
   .venv/bin/python dashboard.py
   ```
4. 장치 화면이 바뀌면 성공이에요. 끝내려면 터미널에서 `Ctrl+C`를 누르세요.

### 2-4. 맥을 켤 때 자동으로 실행하기

```bash
./scripts/install-launchd.sh
```

이제 로그인하면 자동으로 켜지고, 꺼지면 15초 안에 다시 켜집니다. USB를 뽑았다 꽂아도 알아서 다시 연결돼요.

| 하고 싶은 일 | 명령 |
|---|---|
| 설정을 바꾼 뒤 다시 시작 | `launchctl kickstart -k gui/$(id -u)/com.agentdeck.dashboard` |
| 로그 보기 | `tail -f dashboard.log` |

## 3. 화면 기본 사용법

```
┌────┬────┬────┬────┬────┐
│ 1  │ 2  │ 3  │ 4  │ 5  │   ← 페이지마다 바뀌는 칸 (10개)
├────┼────┼────┼────┼────┤
│ 6  │ 7  │ 8  │ 9  │ 10 │
├────┼────┼────┼─────────┤
│ ◀  │ 홈 │ ▶  │ 넓은 칸  │   ← 공통 버튼 + 넓은 칸 (시계 등)
└────┴────┴────┴─────────┘
```

| 버튼 | 짧게 누르기 | 길게 누르기 (0.8초 이상) |
|---|---|---|
| ◀ / ▶ | 이전 / 다음 페이지 | — |
| 가운데 | **홈**(바로가기)으로 가고 바로 새로고침 | 화면 밝기 변경 (20 → 50 → 80 → 100) |

**켜질 때 인트로와 홈**: 대시보드가 켜지면 약 3초 동안 칸들이 물결처럼 켜지고 한 칸에 한 글자씩 **AGENT / DECK** 로고가 나온 뒤(아무 칸이나 누르면 건너뜀) **홈**이 나와요. 홈의 10칸은 각 페이지로 가는 **바로가기**이고, 넓은 칸에는 **업데이트 내용**(지난번 이후 새로 바뀐 것, 누르면 다음 목록)이 보여요.

**업데이트**: 하루 한 번 GitHub에 새 버전이 있는지 확인해서, 있으면 시계와 홈 넓은 칸에 **"새 버전 N"**이 떠요. 홈이나 시계가 보이는 페이지에서 **넓은 칸을 2초 동안 누르고 있으면** 새 버전을 받고(필요하면 패키지도 설치) 대시보드가 다시 켜져요. 내 컴퓨터에서 고친 파일과 겹치면 업데이트하지 않고 알려만 줘요(직접 고친 내용은 지우지 않음).

**색의 의미**는 모든 페이지에서 같아요.

| 색 | 뜻 |
|---|---|
| 🟩 초록 | 여유 있음, 정상, 완료 |
| 🟨 노랑 | 주의, 내 결정이 필요함 |
| 🟥 빨강 | 위험, 거의 바닥남, 지우기 전 확인 대기 |
| 🟦 파랑 | 작업 중 |
| **깜빡임** | 지금 봐야 하는 알림이에요. 누르면 해당 위치로 이동하고 깜빡임이 멈춥니다. |

## 4. 기능별 상세

### 4.1 LLM 남은 한도 (1·2페이지)

<img src="images/page1-summary.png" width="560">

**무엇을 보여주나요?**
- **Claude · Codex · agy**의 남은 한도를 5시간 기준과 주간 기준으로 보여줘요. 큰 숫자는 둘 중 **더 빠듯한 쪽**이에요.
- **페이스**: 한도를 시간보다 빨리 쓰고 있는지 알려줘요. 예를 들어 주간 한도의 50%를 썼는데 일주일 중 30%밖에 안 지났다면 "과속"이에요.
- **지금 쓰기 좋은**: 가장 여유 있는 LLM을 추천해요.
- **2페이지**는 같은 정보를 표처럼 보여줘요. 열은 LLM, 윗줄은 5시간, 아랫줄은 주간이에요. 켜 두면 그 뒤 열에 [Flow · Higgsfield 크레딧](#410-flow--higgsfield-크레딧-선택)도 나와요.
- **안 쓰는 서비스는 칸이 빠져요.** Codex 폴더(`~/.codex`)가 없거나 `agy` 설정이 없으면 그 열을 빼고 앞으로 당겨요. Claude만 써도 화면이 비어 보이지 않아요.

**켜는 방법**

| LLM | 설정 |
|---|---|
| **Claude** | Claude Code 상태줄에 래퍼를 끼워야 해요. 아래 예시를 보세요. |
| **Codex** | Codex CLI에 로그인돼 있으면 자동이에요(`~/.codex/auth.json`). |
| **agy** | `config.json`의 `agy`에 agy를 쓰는 컴퓨터를 적어요. |

**Claude 설정 예시** (`~/.claude/settings.json`)

```jsonc
// 원래 상태줄 명령이 있었다면 뒤에 그대로 붙이세요
"statusLine": {
  "type": "command",
  "command": "/Users/나/agentdeck/statusline-tee.sh 원래명령"
}
// 상태줄을 안 쓰고 있었다면 래퍼만 넣으면 돼요
"statusLine": {"type": "command", "command": "/Users/나/agentdeck/statusline-tee.sh"}
```

> Claude 값은 Claude Code를 쓰는 동안에만 갱신돼요. 한동안 안 쓰면 마지막 값이 그대로 보여요.
> ⚠️ Codex와 agy 조회는 공식 문서가 없는 내부 API를 써요. 언제든 바뀔 수 있습니다.

### 4.2 에이전트 작업 현황 (3페이지)

<img src="images/page3-studio.gif" width="560">

**무엇을 보여주나요?** 지금 돌고 있는 Claude Code · Codex 에이전트를 **프로젝트별**로 묶어서 보여줘요.

| 표시 | 뜻 |
|---|---|
| **결정 N** (노랑 깜빡임) | 권한 승인이나 질문에 답해야 해요 |
| **완료 N** (초록 깜빡임) | 작업이 끝났는데 아직 확인하지 않았어요 |
| **작업 N** (파란 테두리) | 실행 중이에요 |
| **대기** | 다음 지시를 기다려요 |
| `C2 X1 · 실행 1` | C는 Claude, X는 Codex, A는 agy 개수이고, 뒤의 숫자는 지금 실행 중인 수예요 |

**눌렀을 때**
- 깜빡이는 칸을 누르면 **그 에이전트가 있는 창으로 이동**하고 깜빡임이 꺼져요.
- 같은 칸을 다시 누르면 그 프로젝트의 다음 세션이나 탭으로 넘어가요.

**두 가지 방식 중 하나를 고르세요** (`config.json`의 `agent_source`)

#### A. 훅 방식 (`"hooks"`, 추천)
VS Code, Cursor, iTerm, Ghostty, 기본 터미널 등 **어디서 돌든** 동작해요.

```bash
python3 scripts/install-hooks.py           # Claude Code
python3 scripts/install-hooks.py --codex   # Codex도 함께 (기존 notify 설정은 유지)
```

설치한 뒤 **새로 시작한 세션부터** 화면에 나타나요. 누르면 이렇게 이동합니다.

| 에이전트가 도는 곳 | 눌렀을 때 |
|---|---|
| iTerm2, 터미널 앱 | 그 탭으로 정확히 이동 |
| VS Code, Cursor | 그 프로젝트 창을 앞으로 |
| Ghostty 등 그 밖의 앱 | 그 앱을 앞으로 |
| 다른 맥 | 화면에 표시만 돼요 |

다른 맥의 에이전트도 보려면 그 맥에서도 `install-hooks.py`를 실행하고, `config.json`의 `hooks.hosts`에 SSH 주소를 추가하세요.

> 제외되는 것: 다른 프로그램이 `claude -p`처럼 비대화형으로 실행한 작업은 "하위 작업"으로 보고 알림을 띄우지 않아요. VS Code 확장 안의 에이전트처럼 CLI가 아닌 에이전트는 잡히지 않을 수 있어요.

#### B. Herdr 방식 (`"herdr"`)
[Herdr](https://herdr.dev)로 에이전트를 관리한다면 이 방식이 더 많은 기능을 줘요.
- 윗줄에 **리드(총괄) pane**과 하위 에이전트를 따로 보여줘요. pane을 누르면 그 pane을 **확대**하고, 다시 누르면 원래대로 돌아가요.
- `studio` 설정에 Herdr가 도는 컴퓨터, 리드 스페이스와 탭 이름, 리드 pane을 적어주세요. 자세한 내용은 [5. 설정 파일](#5-설정-파일-전체-설명)을 보세요.

### 4.3 워크트리

<img src="images/worktrees.png" width="560">

3페이지의 **넓은 칸을 누르면** 들어가요. git 워크트리를 상태별로 보여줍니다.

| 상태 | 뜻 | 길게 두 번 누르면 |
|---|---|---|
| 방치 | 커밋 안 한 변경이 있는데 아무도 작업하지 않아요 | 리드 에이전트에게 정리 요청을 보내요 |
| 정리 가능 | main에 모두 반영됐고 변경도 없어요 | 워크트리를 삭제해요 (브랜치는 남겨요) |
| 오래됨 | 반영 안 된 커밋이 있고 3일 넘게 손대지 않았어요 | 정리 요청 |
| 작업 | 에이전트가 그 폴더에서 일하는 중이에요 | 정리 요청 |

- **짧게 누르면** 그 워크트리를 열어요.
- **길게 누르면 빨간 확인 대기 상태가 되고, 10초 안에 한 번 더 길게 눌러야 실행돼요.** 실수로 지워지지 않게 하려는 거예요.
- 켜는 방법: `studio.host`(워크트리가 있는 컴퓨터)와 `studio.worktree_globs`(찾을 경로)를 설정하세요. 정리 요청은 `studio.lead_pane`으로 가는데, 이 기능은 지금 Herdr가 필요해요.

### 4.4 머신과 기기 상세 (4페이지)

<img src="images/page4-machines.png" width="560">

**무엇을 보여주나요?** 여러 맥의 CPU, 메모리, 디스크와 외장 드라이브의 남은 용량이에요. [Mole](https://github.com/tw93/Mole)이 설치돼 있으면 **건강 점수**와 정리 가능한 용량도 보여줘요.

**컴퓨터 칸을 누르면 기기 상세 페이지**로 들어가요.

<img src="images/device.png" width="560">

- CPU를 많이 쓰는 프로세스 2개를 보여주고, 5분 넘게 CPU를 과하게 쓰면 빨갛게 표시해요.
- **캐시·로그 정리**: 앱 캐시, 로그, 임시 파일을 지워요(`mo clean`). 관리자 권한이 필요한 시스템 캐시는 건너뛰고 사용자 영역만 정리해요.
- **빌드 산출물 정리**: `node_modules`, `.venv`, `dist` 같은 빌드 결과물을 지워요(`mo purge`). ⚠️ 돌고 있는 프로젝트의 것도 지워질 수 있어서, 다시 설치가 필요할 수 있어요.
- **휴지통 비우기**: 영구 삭제예요.
- 세 버튼 모두 **길게 두 번 눌러야 실행**되고, 짧게 누르면 무엇을 지우는지 설명만 보여줘요.

**켜는 방법**

1. **다른 맥 연결 (선택)**: 비밀번호 없이 SSH로 접속할 수 있어야 해요. 가장 쉬운 방법은 모든 맥에 [Tailscale](https://tailscale.com)을 설치하는 거예요. 그다음 이 맥에서 아래를 실행합니다.
   ```bash
   ssh-keygen -t ed25519            # 키가 없을 때만
   ssh-copy-id 사용자@상대맥이름
   ssh 사용자@상대맥이름 echo ok      # ok 가 나오면 성공
   ```
2. **Mole 설치 (선택)**: 각 맥에서 `brew install mole`
3. `config.json`의 `machines`에 컴퓨터를 추가하세요. 이 맥은 `"ssh": null`, Mole이 있으면 `"mole": true`로 적어요.

### 4.5 뽀모도로 (5페이지)

<img src="images/page5-pomodoro.gif" width="560">

1. 5분부터 90분까지 원하는 시간을 누르면 바로 시작해요.
2. 10칸이 **마지막 칸부터 거꾸로** 비워져요. 넓은 칸에는 남은 시간과 끝나는 시각이 나와요.
3. 아무 칸이나 **짧게 누르면 일시정지**하고, 그때 나타나는 "취소" 칸을 누르거나 **길게 누르면 취소**돼요.
4. 끝나면 어느 페이지를 보고 있든 5페이지로 넘어가서 깜빡이고, 맥 알림과 소리로 알려줘요.

> 대시보드가 다시 시작돼도 타이머는 이어집니다.

### 4.7 게임 (7페이지)

<img src="images/page7-games.gif" width="560">

위 두 줄 10칸이 게임판이 돼요. 메뉴에 게임 일곱 개가 있어요. 게임 칸을 누르면 시작돼요. 넓은 칸은 점수판이고, 최고 기록은 저장돼요.

| 게임 | 방법 |
|---|---|
| 🔨 **두더지 잡기** | 30초 동안 튀어나오는 두더지를 눌러 잡아요. 한 마리 +1, **황금 두더지 +3**, **폭탄은 누르면 -3**. 시간이 갈수록 빨라지고 한 번에 두 마리씩 나와요 |
| 🧠 **순서 기억** | 칸이 순서대로 켜지면 똑같이 따라 눌러요. 맞히면 한 칸씩 늘어나고, 틀리면 끝나요. 끝나면 틀린 칸에 ✕, 정답 칸에 ! 가 보여요 |
| 🃏 **짝 맞추기** | 어항 친구 5쌍(물고기·문어·게·거북이·상어)을 찾아요. 시작할 때 1.5초 동안 전부 보여줘요. **시도 횟수가 적을수록** 좋은 기록이에요 |
| 🃏 **블랙잭** | 윗줄 왼쪽 네 칸은 딜러, 아랫줄 왼쪽 네 칸은 내 카드예요. 오른쪽 위 **딜**로 시작해서 **HIT**(한 장 더)·**STAND**(그만)를 누르고, 처음 두 장일 때 넓은 칸을 누르면 **더블**(베팅 두 배, 한 장만 더). 오른쪽 아래로 베팅을 1·2·5·10코인 중에 골라요. 딜러는 16 이하면 뽑고 17 이상이면 멈춰요. 블랙잭은 3:2로 받아요 |
| 🂡 **포커 대결** | 컴퓨터와 1:1 5장 드로우 포커예요. **윗줄은 상대 카드**(처음 두 장은 보여요), **아랫줄은 내 카드**예요. 대기 중엔 아랫줄에서 베팅(1·2·5·10)을 고르고 **딜**. 남길 내 카드를 **직접 눌러 킵**하고 **넓은 칸**을 누르면 교체돼요. 이어서 상대도 카드를 바꾸고 전부 공개해 승부를 내요. 이기면 건 만큼 더 받고, 스트레이트 이상으로 이기면 보너스(스트레이트 4배 · 플러시 6 · 풀하우스 9 · 포카드 25 · 스트레이트 플러시 50 · 로열 플러시 250). 끝난 뒤 아무 칸 = 같은 베팅으로 다음 판, 넓은 칸 = 베팅 바꾸기 |
| 🏇 **경마** | **윗줄 다섯 칸이 하나로 이어진 경주로**가 되고, 말 다섯 마리가 왼쪽 출발 게이트에서 오른쪽 결승선까지 달려요. **아랫줄은 출전마 카드**(등번호·이름·배당)예요. 아랫줄에서 말을 눌러 고르고(다시 누르면 빼기), **고른 말 수에 따라 승식**이 정해져요: 1마리 **단승**(1착 맞히기), 2마리 **복승**(두 마리가 1·2착, 순서 상관없이) 또는 **쌍승**(고른 순서대로 1착·2착. 두 마리를 고르면 왼쪽 위 칸에 뜨는 **복승 ⇄ 쌍승** 단추로 바꿔요), 3마리 **삼복승**(세 마리가 1·2·3착, 순서 상관없이). 대기 중엔 윗줄 경주로 위에 **베팅 칩**(1·2·5·10코인)이 떠서 눌러 고르고, **넓은 칸**을 누르면 3·2·1 뒤에 출발해요. 달리는 동안 아랫줄에 실시간 순위가, 넓은 칸에 중계("3번 번개 선두로!", "마지막 직선, 접전!")가 나와요. 말마다 컨디션 기복과 막판 뒷심이 달라서 역전이 자주 나요. 출발하면 경주로가 **위 두 줄(10칸)**로 커지고, 선두가 결승선에 다가오면 **아래 줄 버튼과 넓은 칸까지 화면 전체가 결승선을 크게 비추는 슬로우 모션**으로 바뀌고, 승부가 갈리는 순간 셔터처럼 번쩍이며 멈춘 **사진 판정** 장면을 보여 준 뒤 원래 화면으로 돌아와요. 맞히면 **건 코인 × 배당**을 받아요. 배당은 경주마다 미리 1,200번 달려 본 결과로 승식·조합별로 정해져서, 높을수록 맞히기 어려운 조합이에요. 말 카드의 배당은 단승 배당이고, 고른 조합의 배당은 넓은 칸에 나와요. 끝난 뒤 아무 칸 = 다음 경주 |
| 🎰 **슬롯머신** | 양쪽 끝 칸(레버)을 누르면 1코인으로 세 릴이 돌아가고, 아래 **STOP**으로 하나씩 멈춰요. 세 개가 같으면 7은 50, 다이아 30, 별 15, 종 10, 레몬 6, 체리 5코인, 두 개만 같아도 2코인. 20코인으로 시작하고(블랙잭·포커·경마와 같은 코인), 다 잃으면 다시 20코인을 채워 줘요 |

- 칸은 **누르는 순간** 반응해요. 떼기를 기다리지 않아요.
- 게임이 끝난 뒤 판을 누르면 다시 하기, **가운데 버튼**을 누르면 메뉴로 가요. 게임 중에 가운데를 누르면 그만둬요.
- 게임 중에는 화면보호기가 켜지지 않아요.
- **효과음**: D200에는 스피커가 없어서, 덱이 연결된 맥의 스피커로 소리를 내요(두더지 타격, 순서 기억 음계, 카드, 슬롯, 경마 출발 종·말발굽·슬로우 모션·관중 함성 등). `config.json`에 `"sound": {"enabled": true, "volume": 0.6}`을 넣으면 켜져요. 기본은 꺼져 있어요.

### 4.8 멍때리기 화면보호기: 어항 · 불멍 · 비멍 · 바다

<img src="images/page8-aquarium.gif" width="560">

덱 전체(버튼 13칸과 넓은 칸)를 **하나의 화면**으로 써서 픽셀아트 어항을 보여줘요. 물고기가 칸 경계를 넘나들며 헤엄치고, 수초가 흔들리고, 거품이 올라와요. **복어**는 가끔 가시를 세우며 부풀고, **해파리**는 갓을 오므렸다 펴며 떠다니고, **게**는 모래 위를 옆걸음질하다 바닥에 떨어진 먹이를 주워 먹어요. **거북이**는 느긋하게 헤엄치고, **문어**는 모래 위를 기어 다니다 가끔 위로 솟구치며 먹물을 뿜고 몸 색을 바꿔요. **상어**가 순찰하다 가끔 쏜살같이 돌진하면, 근처 물고기들이 흩어져 도망가요.

홈의 **어항**을 누르면 네 가지 장면 중에 골라요. 모두 덱 전체를 한 화면으로 쓰고, 맥 스피커로 어울리는 **배경음**이 끊김 없이 반복돼요(효과음을 켰을 때).

| 장면 | 화면 | 짧게 누르면 | 배경음 |
|---|---|---|---|
| 🐠 물멍 | 위의 픽셀아트 어항 | 먹이 | 물소리 · 기포 |
| 🔥 불멍 | 돌 벽난로 안에 엇갈려 쌓은 장작이 타오름, 불티와 숯불 | 장작을 던져 불길이 확 일어남 | 장작 타는 소리 |
| 🌧️ 비멍 | 창가에서 보는 비 오는 밤거리: 빗물에 번진 불빛, 가로등, 젖은 도로, 유리창 물방울, 창틀의 화분과 머그컵 | 번개 · 천둥 | 빗소리 |

- ▶로 8페이지에 오면 바로 켜지고, **아무것도 누르지 않은 채 10분**이 지나면 화면보호기로 자동으로 켜져요. 시간은 `config.json`의 `"screensaver_min"`으로 바꾸고, `0`이면 자동 실행을 꺼요.
- 화면보호기 중에 **에이전트 알림이나 뽀모도로 종료**가 생기면 자동으로 해당 페이지로 돌아가요.
- 1초에 5번 화면을 바꿔요. 한 장면이 약 11KB라 장치에 부담이 적어요.

### 4.9 알리 택배 도착 예상 (선택)

`config.json`에 `"parcels": {"enabled": true}`를 넣으면 게임 다음에 **택배 페이지**가 생겨요. 알리익스프레스 주문을 택배 상자 단위(같은 운송장끼리 묶음)로 보여줘요.

- 칸마다 상품 이름, **"오늘 / 내일 / 3일 뒤"**, 단계(주문 → 발송 → 해외 운송 → 통관 → 국내 배송 → 배송 출발 → 도착) 막대예요. 오늘 오거나 배송 출발한 건 깜빡이고, 시계에 "택배 오늘 N" 칩이 떠요.
- 넓은 칸은 **앞으로 2주 날짜별 도착 예상 그래프**예요. 칸을 짧게 누르면 그 택배의 이동 기록, **길게 누르면 맥 브라우저에 알리 배송 조회** 페이지가 열려요.
- **처음 한 번 로그인**: `.venv/bin/python parcels_import.py login` → 택배 전용 Chrome 창이 열리면 알리에 직접 로그인해요. 이 전용 프로필(`~/.cache/d200/ali-browser`)은 평소 Chrome과 따로예요.
- 그다음부터는 **3시간마다 화면 없이** 주문·운송장·예상 도착일을 다시 가져오고, 운송장은 30분마다 알리 물류 조회로 갱신해요. 바로 가져오려면 `.venv/bin/python parcels_import.py`.
- 안전: 비밀번호는 저장하지도 입력하지도 않아요. 브라우저 접속은 이 맥 안(127.0.0.1)에서만 하고, 주문 페이지에서는 **"주문 더 보기" 단추만** 눌러요(배송 완료 확인·취소 등은 누르지 않음). 가져온 내용은 `~/.cache/d200/parcels.json`에만 저장돼요.
- 운송장을 직접 넣을 수도 있어요: `.venv/bin/python parcels.py add <운송장> "상품 이름"`.

### 4.10 Flow · Higgsfield 크레딧 (선택)

Google Flow와 Higgsfield는 남은 크레딧을 **웹 화면에서만** 보여줘요. 켜 두면 2페이지 한도 표의 LLM 다음 열에 나와요.

- **윗칸**: 남은 크레딧. Flow는 초기화까지 남은 시간, Higgsfield는 월 한도 대비 막대를 같이 보여줘요.
- **아랫칸**: 요금제 이름과 마지막으로 읽은 시각. 3시간 넘게 못 읽으면 회색으로 바뀌어요.

**켜는 방법**
1. `config.json`에 쓰는 서비스만 켜요: `"flow": {"enabled": true}`, `"higgsfield": {"enabled": true}`.
2. **처음 한 번 로그인**: `.venv/bin/python web_credits.py login flow` (Higgsfield는 `login higgsfield`). 덱 전용 Chrome 창이 열리면 직접 로그인하고 창을 닫아요. 택배 기능과 같은 전용 프로필(`~/.cache/d200/ali-browser`)을 써서, 한쪽에서 구글로 로그인했다면 다른 쪽도 이미 로그인돼 있을 수 있어요.
3. 대시보드를 다시 시작하면 **30분마다 화면 없이** 읽어 와요. 바로 확인하려면 `.venv/bin/python web_credits.py`.

- 안전: 비밀번호는 저장하지도 입력하지도 않아요. 브라우저 접속은 이 맥 안(127.0.0.1)에서만 해요. Flow는 계정 단추를 눌러 크레딧 칸만 읽고, Higgsfield는 구독 설정 화면 글자만 읽어요. 로그아웃·구매 같은 단추는 누르지 않아요.
- 저장하는 값은 크레딧 수, 월 한도, 초기화 시각, 요금제 이름뿐이에요(`~/.cache/d200/flow.json`, `higgsfield.json`). 이메일·이름은 저장하지 않아요.
- ⚠️ 공식 API가 아니라 웹 화면을 읽는 방식이라, 사이트 화면이 바뀌면 못 읽을 수 있어요. 그러면 마지막 값이 회색으로 남아요.

  "higgsfield": {"enabled": false}, // Higgsfield 남은 크레딧 (2페이지)

  "hooks": {
    "hosts": [null, "studio"]   // 훅 상태를 읽을 컴퓨터 (null = 이 맥)
  },

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| 화면이 안 바뀌어요 | Ulanzi Studio를 완전히 종료하고, 장치를 다시 꽂고, 대시보드를 다시 시작하세요 |
| 버튼을 누르면 글자가 입력돼요 | 대시보드가 꺼져 있어서 장치가 기본 키보드 모드로 동작하는 거예요. `dashboard.log`에서 오류를 확인하세요 |
| 에이전트가 안 보여요 (훅 방식) | 훅을 설치한 뒤 **새로 시작한 세션**부터 보여요. `ls ~/.cache/d200/agents`에 파일이 생기는지 확인하세요 |
| 다른 맥 칸이 "OFF"예요 | `ssh 주소 echo ok`가 비밀번호 없이 되는지 확인하세요 |
| 맥북 휴지통 비우기를 누르면 권한을 물어요 | 처음 한 번 "Finder 제어 허용"을 눌러주세요 |
| Claude 한도가 "-"예요 | 상태줄 래퍼 설정을 확인하고 Claude Code를 한 번 사용하세요 |

## 7. 제거하기

```bash
launchctl bootout gui/$(id -u)/com.agentdeck.dashboard
rm ~/Library/LaunchAgents/com.agentdeck.dashboard.plist
python3 scripts/install-hooks.py --uninstall   # 훅을 설치했다면
```

Claude 상태줄 설정은 원래대로 되돌리고, 폴더를 지우면 끝이에요. 장치는 Ulanzi Studio로 바로 다시 쓸 수 있어요.
